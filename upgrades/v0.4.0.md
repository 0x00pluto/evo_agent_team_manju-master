# v0.4.0

相对 `v0.3.2`：操作台先出提示词，再按角色确认本账号音色后才配音。

## 变更

- 「生成提示词」不再同时合成 MP3。未绑定音色、未填 MiniMax 密钥时，人物、场景和分镜仍可复制
- 说话人保留脚本原名。有旁白句时旁白单独占一行。每一行都绑到可用音色后，才能「生成配音」
- 音色库带 AI企业主、女招商主管两份默认样音。须在本账号点「生成可用音色」后才可用于合成。可以换成新声音，也可以添加音色
- 企业主、企业老板会默认对上 AI企业主，招商运营、招商顾问、招商主管会默认对上女招商主管。人手改过的选择不会被盖掉
- 没有 MP3 时，配音页只留「生成配音」。配完才出现「打开所在文件夹」和「下载全部」
- 没有绑定记录的历史集，单条重配仍沿用该条已经写下的声音

## 升级注意

- clone / 切换到本 tag：`git clone --branch v0.4.0 https://github.com/0x00pluto/evo_agent_team_manju-master.git`
- 核对根目录 `evo_agent_pack.json` 的 `version` 为 `0.4.0`（不含 v）
- 核对 `plugin.manifest.json` 的 `version` 为 `0.4.0`。插件中心的 tag 必须和这份清单一致
- 已从插件中心装过更低版本时，目录出现 `0.4.0` 后列表应显示可更新。覆盖安装只换安装目录。成片、分镜事实和音色库留在 `plugin-data/manju-studio/`
- 同事装好后要在自己的 MiniMax 账号里生成可用音色。包内旧的 `voice_id` 不会拿去合成
- 克隆样音需要本机有 ffmpeg。音轨须在 10 秒到 5 分钟，且不超过 20MB
