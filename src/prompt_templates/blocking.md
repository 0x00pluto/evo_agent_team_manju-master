# 空间站位规则（思考顺序，不是动作黑名单）

生成分镜时按下面顺序思考。站位推理只放在思维链里，最终输出仍只有九要素，不要多写「站位」栏。

## 1. 先空间

先用一两句在思维里定场：

- 谁在画面左/右，或过肩时谁在前景（后脑/肩）、谁在远端（脸）
- 两人朝向：相对 / 同向 / 对镜头
- 大致距离、是否已在画内
- 光方向服从朝向：面对面则不要写「两人共用身后同一太阳」

## 2. 再运镜

机位怎么动都可以，但必须还在这套已定空间里拍。不要靠运镜把人「变」到另一套阵（例如过肩里人已在场，却用横移伪装「入画」来换阵）。

## 3. 再表演

允许走、转、手势、看环境。要求是**时长内能从起幅位置连续做完**。

- 可以面对面开场，再一起转身看园区——但必须写出转身/走动过程，不能起幅和收幅像两套摆拍拼在一起。
- 过肩双人 = 两人已在这个空间；除非空间里明确有人在画外，否则不要写「入画」「走入」。
- **禁止无路径换阵**：同一镜里两套阵同时成立（既面对面过肩、收幅又已经并肩看园），中间没有转身/走动过程。

不要默认把人钉成站桩；也不要为了「站位安全」删掉合理的走、转、手势。
