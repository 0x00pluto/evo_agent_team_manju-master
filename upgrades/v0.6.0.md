# v0.6.0

相对 `v0.5.0`：开场先加载脚本并选段，确认后再进入下一页生成提示词。

## 变更

- 第一页标题是「加载脚本」。飞书链接、上传文本、粘贴正文一次只用一种。选定文件后不立刻分段，要点「加载」
- 改来源、改内容或改分段方式时，旧分段立刻消失。解析失败时列表保持空白
- 有分段后点「下一步」。第二页只读回顾选段，再点「生成提示词」。失败留在这一页，不配音
- 「返回」仍回到刚才那份脚本。要另起一份，点左上角「AI漫剧大师」

## 升级注意

- clone / 切换到本 tag：`git clone --branch v0.6.0 https://github.com/0x00pluto/evo_agent_team_manju-master.git`
- 核对根目录 `evo_agent_pack.json` 的 `version` 为 `0.6.0`（不含 v）
- 核对 `plugin.manifest.json` 的 `version` 为 `0.6.0`。插件中心的 tag 必须和这份清单一致
- 已从插件中心装过更低版本时，目录出现 `0.6.0` 后列表应显示可更新。覆盖安装只换安装目录。成片、分镜事实和音色库留在 `plugin-data/manju-studio/`
