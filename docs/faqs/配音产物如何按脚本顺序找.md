# 配音产物如何按脚本顺序找

## 结论

配音 `id` 必须用整集口播时间线的两位序号（`01`、`02`…），产物命名 `{id}_{owner|advisor}.mp3`。在资源管理器里**按文件名排序即播放顺序**。

禁止用 `H01` / `M01` / `C01` 这类段落前缀当主键：字典序会把 `C` 提前、`M` 插在中间，找文件要靠猜。

## 顺序跟谁

跟**口播全稿**，不跟 LibTV 分镜镜号。

视频 episode 可以只做钩子+升华+CTA 三镜，中间价值旁白仍要配音。正确时间线一般是：

钩子 → 中间痛点 → 规格长 VO → 升华 → CTA

不要把「升华」因为也在分镜 YAML 里就紧挨着钩子排到配音清单前面。

## 改错了怎么办

1. 改 `assets/episodes/<主题>-voiceover.json` 的 `id` 与 `lines` 顺序。
2. 若音频内容没错：按旧→新映射**改名** mp3/txt，刷新 `manifest-out.json`，不必重打 TTS。
3. 若文案也变了：`--only <新id>` 重配该句。

详见 [`docs/workflows/episode-voiceover.md`](../workflows/episode-voiceover.md)。
