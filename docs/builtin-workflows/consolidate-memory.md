# 记忆巩固与遗忘

仓级记忆卫生手册。审视本仓长期记忆面与近轮增量，按**冲突消解 → 情景提纯 → 剪枝**，去掉过期信息，留下可迁移规则与负面约束。

**仅**在用户明确要求「遗忘 / 记忆巩固 / consolidate-memory / 剪枝记忆」时触发。**禁止**任务结束后自行启动。不要只在聊天里写总结而不改文件。

与兄弟流分工（手动触发、互不串联）：

| 流 | 管什么 |
|---|---|
| [`post-task-reflect.md`](./post-task-reflect.md) | 本轮**步骤**该不该存在（删 → 程序化） |
| [`extract-experience.md`](./extract-experience.md) | 抽到**项目无关**最佳实践 |
| **本篇** | 本仓常驻约定里的冲突、过期事实、一次性专名剪枝 |

## 入口

按下方「日常步骤」改仓内 Markdown；有变更才落盘。

## 参数

| 参数 | 说明 |
|---|---|
| 长期记忆面 | 默认：`AGENTS.md`、`docs/workflows/`、`docs/faqs/`、`docs/doc_index.md` |
| 增量范围 | 近轮改过的 docs / FAQ；对话里新立的一次性主题名、临时禁令、临时别名；可选 `git diff` |
| 提示词 / 风格资产 | 默认**只读**（只标冲突）；用户点名才改 |

## 日常步骤

顺序不可颠倒：

```text
读记忆面 + 增量
→ 1 冲突与时效检测
→ 2 提纯与合并
→ 3 剪枝落盘
→ 回复 refactoring_summary
```

从长期记忆面与增量开始。提示词 / 风格资产默认只读。

### 1. 冲突与时效检测

对每条候选记忆问：

1. 是否与更新的约定矛盾？（例：新约定「按输入决定」vs 旧句「第三路一律不做」）
2. 是否已失效的环境快照？（密钥前缀、shell 布局、临时任务状态、已修死循环）
3. 是否只对这一次有用？（一次性主题名、临时路径别名、某次专属对照表写进仓级 FAQ）

先标出：冲突 / 失效 / 可删的一次性信息。**尚未落盘。**

### 2. 提纯与合并

- **情景 → 规则**：删掉故事，留下定律（`401 + 某 key` → 「401=换 key；禁止某回退路径」）。
- **试错 → SOP**：成功路径写入或改短 `docs/faqs/` / `docs/workflows/` 检查清单。
- **落点**：

| 类别 | 落哪里 |
|---|---|
| 事实约定 | AGENTS 环境/目录；workflow 参数 |
| 做法 | workflows 日常步骤；FAQ 跨任务规则 |
| 负面约束 | 「禁止…」节（**优先于**普通事实） |

不确定的临时猜测**不进**长期记忆。

### 3. 剪枝落盘

- 删除过期信息；提纯后的规则留下。
- 有变更才改文件；同步 [`docs/doc_index.md`](../doc_index.md) 摘要。
- 在对话里给出 `refactoring_summary`（见下）。真相在改完的 Markdown，不要另存一份 JSON 当唯一真相。

### 绝不可删

- **负面约束**（「禁止…」）——剪枝时严禁漏删后反写成「可以回退」
- **仍成立的跨任务规则与入口脚本约定**——不得抹掉已有禁止句
- **提示词 / 风格资产**——默认不删不改；用户点名才动

回复摘要（对话内即可）：

```json
{
  "refactoring_summary": {
    "forgotten_entries": ["删除了废弃信息：[原因及原条目]"],
    "consolidated_skills": ["提纯的通用规则：[描述]"],
    "resolved_conflicts": ["[旧条目] -> [新条目]"]
  }
}
```

## 产物

- 若有变更：更新后的 `AGENTS.md` / `docs/workflows/` / `docs/faqs/` / `docs/doc_index.md`
- 对话内 `refactoring_summary`
- 不是跨项目 `docs/best-practices/`（那走 extract-experience）
- 无可剪 → 写明并结束（合法）

## 失败排查

| 现象 | 处理 |
|---|---|
| 只写了摘要，仓没变 | 有该删/该提纯则必须改文件；否则写「无可剪」并停 |
| 任务结束后自动跑了本流 | 停；仅用户明确要求时触发 |
| 删掉了「禁止…」类负面约束 | 立刻恢复；重跑提纯与剪枝，负面优先 |
| 把一次性主题名/对照表写进仓级 FAQ | 移回本任务原料或 prompt；FAQ 只留跨任务规则 |
| 改了提示词 / 风格但用户未点名 | 回滚；默认只读标冲突 |
| 与 post-task-reflect / extract-experience 串成一套 | 停；三流互不串联 |
| 在本流里再次触发本流 | 套娃；直接结束 |
| 新建平行记忆目录或 JSON 当唯一真相 | 禁止；只改版本化 Markdown |

## 测试

- 仓级 docs 更短或冲突表述减少
- `refactoring_summary` 中 forgotten / resolved 与 diff 对应
- 负面约束与跨任务规则仍在索引可达路径上
