# v0.3.1

相对 `v0.3.0`：插件中心的安装包只收操作台运行需要的文件。

## 变更

- 仓库根增加 `dex-buddy-plugin.pack`，列出清单、入口、图标、`requirements.txt`、`src/` 和 `assets/`
- 测试、文档、命令行脚本和工牌不再打进插件中心的 zip

## 升级注意

- clone / 切换到本 tag：`git clone --branch v0.3.1 https://github.com/0x00pluto/evo_agent_team_manju-master.git`
- 核对根目录 `evo_agent_pack.json` 的 `version` 为 `0.3.1`（不含 v）
- 核对 `plugin.manifest.json` 的 `version` 为 `0.3.1`。插件中心的 tag 必须和这份清单一致
- 已从插件中心装过更低版本时，目录出现 `0.3.1` 后列表应显示可更新。覆盖安装只换安装目录，`plugin-data/manju-studio/` 里的成片和分镜事实留下
