# v0.8.0

相对 `v0.7.0`：打开插件前检查本机 `ffmpeg` 与 `ffprobe`，MiniMax 密钥改为在控制台申请。

## 变更

- 清单声明外部命令 `ffmpeg`，并带上 `ffprobe`。Dex Buddy 打开插件前只检查 PATH，两条都在才挂上服务。缺了给出可复制的安装说明，参考 https://ffmpeg.org/download.html。宿主不下载、不代装，装好后点「重试」
- 命令行和浏览器里的操作台不走这次检查，仍要系统 PATH 里有这两条命令
- MiniMax 密钥说明改为在 https://platform.minimax.io/console/access 申请。合成仍走国际站 `https://api.minimax.io`

## 升级注意

- clone / 切换到本 tag：`git clone --branch v0.8.0 https://github.com/0x00pluto/evo_agent_team_manju-master.git`
- 核对根目录 `evo_agent_pack.json` 的 `version` 为 `0.8.0`（不含 v）
- 核对 `plugin.manifest.json` 的 `version` 为 `0.8.0`。插件中心的 tag 必须和这份清单一致
- 本机没有 `ffmpeg` 或 `ffprobe` 时，插件不会进入操作台。按说明装到 PATH 后再点「重试」
- 已从插件中心装过更低版本时，目录出现 `0.8.0` 后列表应显示可更新。覆盖安装只换安装目录。成片、分镜事实和音色库留在 `plugin-data/manju-studio/`
