# v0.2.0

相对 `v0.1.0`：操作台按 Dex Buddy 插件中心发布，配音与飞书读文档改在本仓完成。

## 变更

- 漫剧操作台补上插件清单和入口。作者只推 tag，Action 打源码 zip；清单声明 Python 运行时，由同事机器上的 Dex Buddy 按 requirements.txt 安装依赖
- 装进 Dex Buddy 之后，`temp/` 与 `output/` 写到用户数据目录；密钥放在 Dex Buddy 设置页
- 整集口播改为本仓直接调用 MiniMax；飞书文档改为本仓直接读取
- 光谷生物医药样例的结尾口播改了一句

## 升级注意

- clone / 切换到本 tag：`git clone --branch v0.2.0 https://github.com/0x00pluto/evo_agent_team_manju-master.git`
- 核对根目录 `evo_agent_pack.json` 的 `version` 为 `0.2.0`（不含 v）
- 核对 `plugin.manifest.json` 的 `version` 为 `0.2.0`。插件中心的 tag 必须和这份清单一致
- 整集配音不再使用兄弟仓参数 `--sibling-root`。`MINIMAX_API_KEY` 与飞书应用凭证写在本仓 `.env`，或写在 Dex Buddy 设置页
