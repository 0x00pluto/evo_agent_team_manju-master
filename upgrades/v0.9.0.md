# v0.9.0

相对 `v0.8.0`：提示词和模型分段改走 Dex Buddy 对话；官方清单 id 换成 `app-dexbuddy-manju-studio`。

## 变更

- 命令行、浏览器操作台和插件都不再调用 DeepSeek。对话走 Dex Buddy 渠道 chat，模型由 `list()` 里 `kind=chat` 决定
- 装进 Dex Buddy 后，对话记在登录账号上。设置页去掉 DeepSeek 密钥、模型和接口地址，只留飞书和 MiniMax
- 独立运行用本机 `.env` 的 `DEX_BUDDY_API_KEY`（`dbh_sk_` 开头）。不要放进插件设置，也不要打进 zip
- 只有「让模型分段」和「生成提示词」会先校验买断。按标题加载、配音、历史、打开文件夹不校验
- 安装包带上 `lib/` 里的 Node 与 Python SDK。失败时把网关原文写进错误，分段与提示词请求带 `json_object` 和 `max_tokens`
- 官方清单 `id` 改为 `app-dexbuddy-manju-studio`。侧栏仍显示「漫剧操作台」

## 升级注意

- clone / 切换到本 tag：`git clone --branch v0.9.0 https://github.com/0x00pluto/evo_agent_team_manju-master.git`
- 核对根目录 `evo_agent_pack.json` 的 `version` 为 `0.9.0`（不含 v）
- 核对 `plugin.manifest.json` 的 `version` 为 `0.9.0`。插件中心的 tag 必须和这份清单一致
- 本机命令行删掉 `DEEPSEEK_*`，改填 `DEX_BUDDY_API_KEY`
- 已买 `manju-studio` 的记录对不上新 id，需要按新插件再买
- 装进 Dex Buddy 后数据目录是 `plugin-data/app-dexbuddy-manju-studio/`。旧的 `plugin-data/manju-studio/` 不会自动迁过去
- 开发软链接改成 `plugins/app-dexbuddy-manju-studio`，或继续用 `extraPluginPaths` 指向本仓
