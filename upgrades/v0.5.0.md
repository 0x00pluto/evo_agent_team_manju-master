# v0.5.0

相对 `v0.4.0`：新建克隆音色按「项目-是谁-时间」编号。操作台只管理自己的音色库，不列出、不删除账号里其他克隆声音。

## 变更

- 新建 `voice_id` 写成 `Manju-{是谁}-{yyyyMMddHHmmss}`。不再使用 `V` 加随机串
- 账号里已经有的旧编号继续复用，不为了补减号再克隆。AI企业主、女招商主管仍用 `AiEnterpriseOwner`、`FemaleZhaoShangLead`
- 换成新声音后，这条音色自己的旧编号若没有成片还在用，会删掉以腾出名额
- 角色声音页只保留音色库和添加音色。不管理 MiniMax 账号里其他项目的克隆声音

## 升级注意

- clone / 切换到本 tag：`git clone --branch v0.5.0 https://github.com/0x00pluto/evo_agent_team_manju-master.git`
- 核对根目录 `evo_agent_pack.json` 的 `version` 为 `0.5.0`（不含 v）
- 核对 `plugin.manifest.json` 的 `version` 为 `0.5.0`。插件中心的 tag 必须和这份清单一致
- 已从插件中心装过更低版本时，目录出现 `0.5.0` 后列表应显示可更新。覆盖安装只换安装目录。成片、分镜事实和音色库留在 `plugin-data/manju-studio/`
- 同事装好后要在自己的 MiniMax 账号里生成可用音色。包内旧的 `voice_id` 不会拿去合成
