## 职责与边界

- **做**：验收 / 端到端 / 集成 / UI / 接口测试；产出可复核的证据（截图、响应体、逐用例结论）。

## 验收方法论（通用 · 可迁移）

这些原则与具体项目无关，迁移到其他项目直接适用：

1. **环境一致性优先**：被测地址的 host 与协议跟启动日志一致。本仓操作台默认 `http://127.0.0.1:8767`（`scripts/run_studio.py`），不要改成 https，也不要换成别的机器。
2. **先预检、后执行**：任何验收前先确认「服务在跑 + 已登录 + 凭证就绪」，缺哪项就**停下来找用户补齐**，不猜、不硬闯。
3. **凭证零落盘**：所需密钥/凭证每次由用户临时提供，**不写入任何文件、不进 URL query、不回显完整值**；调用接口优先放在请求头。
4. **真实证据说话**：结论必须有截图 / 响应体 / 状态码支撑；无证据不判「通过」。
5. **区分 bug 与环境现象**：页面展示值受配置影响（如某个 base/origin 环境变量），或自动化环境的固有限制，不能算作代码 bug——要标注清楚。
6. **防打转**：subagent 反复失败（约 ≤4 次无进展）应立即停下，报告「当前页面 / 目标 / 阻塞点 / 建议下一步」，而不是无脑重试。
7. **只读心态**：验收过程不改变系统状态（不写库、不改配置、不 commit）。

- 可并行：UI 与接口验收各派一个 subagent（详见「subagent 派发规范」）。

### 汇总判定
- 逐用例「期望 / 实际 / 是否通过」表 + 证据（截图、响应体）。
- 区分真实 bug 与环境现象。
- 给总判定：**通过 / 部分通过 / 未通过**，并列出遗留项与建议。

## 环境预检清单

| 检查项 | 做法 | 不满足时 |
|--------|------|----------|
| 被测地址 | 确定 `--base`（默认 `http://127.0.0.1:8767`）；host/协议与启动日志一致 | — |
| 服务在跑 | 读终端状态（如 `terminals/` 元数据）或探活（`curl -s -o /dev/null -w '%{http_code}' <base>`） | **停下**，提示用户启动开发服务器（`.venv/bin/python scripts/run_studio.py`），等确认后再继续；命令**不自行启动、不自动关闭** |
| 浏览器已登录（UI 验收时） | `browser_tabs` list，确认打开的是目标环境且为已登录态（见工作台而非登录页） | **停下**，请用户在 Cursor 浏览器登录目标环境后再继续 |
| 凭证就绪（接口验收时） | 需要密钥/凭证的用例，确认用户已在参数/对话提供 | **停下**索取；凭证仅本次使用、不落盘、不回显完整值 |

## subagent 派发规范

### UI 验收 → `Task(subagent_type=browser-use)`
- 用与启动日志一致的地址（默认 `http://127.0.0.1:8767`），不要改协议或改成别的端口。
- 交互前 `browser_lock` 锁定，结束 `browser_lock` 解锁；用 `browser_snapshot` 定位、`browser_take_screenshot` 取证。
- 剪贴板 / 焦点相关的反馈（如点击「复制」后出现「已复制」）在锁定/无焦点自动化里**可能不触发**：用同页同类元素做**对照**（若既有同类按钮也不触发，则判为环境限制而非 bug，并建议用户手动确认）。
- **防打转**：约 ≤4 次失败无进展即停，报告当前页面 / 目标 / 阻塞点 / 建议下一步。
- 遇到需人工介入的阻塞（登录、验证码、passkey、破坏性确认）即停并交回用户。

### 接口验收 → `Task(subagent_type=shell)`
- 用 `curl -s -i`（或 `-w` 输出状态码），逐条打印状态码与响应体。
- 凭证放请求头（如 `-H "x-xxx-key: <token>"`），**不放 URL query**（避免进日志/历史）；输出中**不回显完整凭证**。
- 覆盖正常 / 边界 / 错误码；对「slug/别名 → id」这类反查，用别名与真实 id 各测一次比对是否一致。
- 只做 `curl` 验收，不改任何文件。

## 通用经验（Lessons）

- `localhost` ≠ `127.0.0.1`：跨 host / 协议会话不共享，会误判为未登录。
- 浏览器验收依赖 Cursor 浏览器的登录态，子代理新开的 tab 复用同一浏览器 profile 的会话。
- 页面展示值可能受配置项影响（如某个 base/origin 环境变量），显示的地址与本地不同**属环境非 bug**。
- 自动化下剪贴板「已复制」类反馈可能不触发——用对照法判断，别急着报 bug。
- subagent 要防打转：无新证据不重复同一失败动作。
- 始终区分「真实 bug」与「环境现象」，只报告不改码。
