# v0.3.0

相对 `v0.2.0`：把插件版本升到 `0.3.0`，用来核对插件中心的更新和升级。

## 变更

- `plugin.manifest.json` 与工牌版本改为 `0.3.0`
- 操作台的用法与 `0.2.0` 相同，没有新的制作功能

## 升级注意

- clone / 切换到本 tag：`git clone --branch v0.3.0 https://github.com/0x00pluto/evo_agent_team_manju-master.git`
- 核对根目录 `evo_agent_pack.json` 的 `version` 为 `0.3.0`（不含 v）
- 核对 `plugin.manifest.json` 的 `version` 为 `0.3.0`。插件中心的 tag 必须和这份清单一致
- 已从插件中心装过 `0.2.0` 时，目录出现 `0.3.0` 后列表应显示可更新。覆盖安装只换安装目录，`plugin-data/manju-studio/` 里的成片和分镜事实留下
