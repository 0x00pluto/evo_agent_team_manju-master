# v0.7.0

相对 `v0.6.0`：分镜提示词复制进 LibTV 后，只需删掉开头的时长标题。

## 变更

- 参考图按出镜角色留 `{{Mixed N}}` 三视图，最后一张只留场景占位。场景行与这张占位一致，不再写入段落标题，也不再附「可选面部特写」
- 查看结果里的人物、场景、分镜提示词整段显示，由页面上下滚动
- 加载脚本和生成提示词两页按原文顺序列出每段口播全文。空段写明「这一段没有口播」
- 本机操作台在没有生成任务时，发现 `src/` 下的 Python 有改动会自动重启。页面和提示词模板仍是每次从磁盘读取
- 场景贴图保持主位空镜。运镜总表不注入分镜，园区短剧只用其中一组手法

## 升级注意

- clone / 切换到本 tag：`git clone --branch v0.7.0 https://github.com/0x00pluto/evo_agent_team_manju-master.git`
- 核对根目录 `evo_agent_pack.json` 的 `version` 为 `0.7.0`（不含 v）
- 核对 `plugin.manifest.json` 的 `version` 为 `0.7.0`。插件中心的 tag 必须和这份清单一致
- 已从插件中心装过更低版本时，目录出现 `0.7.0` 后列表应显示可更新。覆盖安装只换安装目录。成片、分镜事实和音色库留在 `plugin-data/manju-studio/`
